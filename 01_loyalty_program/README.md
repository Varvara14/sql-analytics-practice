# Loyalty Program — Расчет персональных скидок

## Бизнес-задача

Для каждого клиента и ресторана рассчитать персональную скидку на основе истории заказов:
- 1 заказ → 10.5%
- 2 заказа → 22%
- 3+ заказов → 30%

## Файлы

| Файл | Что делает |
|------|-----------|
| `01_create_discounts_table.sql` | Создает таблицу `person_discounts` |
| `02_insert_rfm_discounts.sql` | Рассчитывает скидку и вставляет данные |
| `03_apply_discount_to_orders.sql` | Показывает цену со скидкой для каждого заказа |

## Результат

Таблица с персонализированными скидками и запрос для их применения в заказах.
