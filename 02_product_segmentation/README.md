# Product Segmentation — Функция для анализа поведения

## Бизнес-задача

Найти пиццерии, которые:
- клиент **посетил** в указанную дату
- **И** где он мог купить пиццу дешевле заданной суммы

## Файлы

| Файл | Что делает |
|------|-----------|
| `01_fn_visits_and_eats_on_date.sql` | Создает PL/pgSQL функцию с параметрами `pperson`, `pprice`, `pdate` |
| `02_example_calls.sql` | Примеры вызова функции (с разными параметрами) |

## Параметры по умолчанию

- `pperson` → 'Dmitriy'
- `pprice` → 500
- `pdate` → '2022-01-08'

## Результат

Готовый инструмент для менеджера: «покажи рестораны, где клиент X мог бы поесть дешевле Y в день Z».
