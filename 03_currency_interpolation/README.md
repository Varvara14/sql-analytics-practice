# Currency Interpolation — Пересчет баланса в USD

## Бизнес-задача

У нас есть балансы пользователей в разных валютах. Курсы валют обновляются нерегулярно. Для каждой транзакции нужно:
- найти **ближайший курс в прошлом** (если есть)
- если нет — взять **ближайший курс в будущем**
- пересчитать сумму в USD

## Файлы

| Файл | Что делает |
|------|-----------|
| `01_create_tables.sql` | Создает таблицы `user`, `currency`, `balance` |
| `02_nearest_rate_query.sql` | Основной запрос с интерполяцией курса |

## Ключевая логика

Для каждой строки `balance` запрос ищет:
- `rate_before` — последний курс до даты транзакции
- `rate_after` — первый курс после даты транзакции
- Итоговый курс: `COALESCE(rate_before, rate_after)`

## Результат

Каждая транзакция пересчитана в USD даже при пропущенных курсах.
