# Route Optimization — Задача коммивояжера (TSP)

## Бизнес-задача

Дан граф из 4 городов со стоимостью переездов. Нужно:
- найти **все возможные маршруты**, стартуя из города 'a'
- посчитать общую стоимость каждого маршрута
- вывести **минимальный** и **максимальный** по стоимости тур

## Файлы

| Файл | Что делает |
|------|-----------|
| `01_create_graph_table.sql` | Создает таблицу `troute` с городами и стоимостями |
| `02_tsp_min_cost.sql` | Рекурсивный запрос — только минимальный маршрут |
| `03_tsp_min_max_cost.sql` | Рекурсивный запрос — минимальный и максимальный |

## Логика решения

Рекурсивный CTE строит все возможные маршруты длиной 4 города, исключая повторения. Затем:
- для каждого маршрута добавляется стоимость возврата в 'a'
- выбираются маршруты с минимальной и максимальной суммой

## Ключевые техники

- Рекурсивный CTE для перебора всех путей
- `POSITION(... IN visited)` для исключения повторных городов
- JOIN на обратный путь для возврата в стартовую точку
